# 🎵 Sistema Musical

## 📌 Sobre o Projeto

O **Sistema Musical** é um projeto desenvolvido em HTML5 e CSS3, com o objetivo de apresentar uma plataforma para organização e gerenciamento de artistas e músicas.

O sistema possui páginas para login, cadastro de artistas, cadastro de músicas e listagem dos registros. A proposta é oferecer uma interface simples, organizada e de fácil navegação, permitindo que o usuário acesse as diferentes áreas por meio de menus e links.

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma interface web que simule um sistema de gerenciamento musical, colocando em prática conhecimentos de estruturação de páginas HTML e estilização com CSS.

## ⚙️ Funcionalidades

O projeto apresenta as seguintes funcionalidades na interface:

- 🔐 **Login:** página inicial para entrada no sistema.
- 🏠 **Página principal:** menu de navegação para acessar as demais áreas.
- 🎤 **Cadastro de artistas:** formulário com campos para inserir informações dos artistas.
- 🎧 **Cadastro de músicas:** formulário para preencher informações das músicas.
- 📋 **Listagem de músicas:** tabela para visualizar os registros apresentados.
- 🔎 **Pesquisa e filtros:** campos disponíveis para pesquisar e filtrar músicas.
- ✏️ **Edição:** opções de edição exibidas nas listagens.
- 🗑️ **Exclusão:** opções de exclusão disponíveis na interface.

## 💻 Tecnologias Utilizadas

- HTML5 — responsável pela estrutura e organização das páginas.
- CSS3 — utilizado para cores, fontes, espaçamentos, alinhamentos e aparência visual do sistema.

## 📁 Estrutura do Projeto

Os arquivos estão organizados da seguinte maneira:

- `index.html` — página principal do sistema.
- `login.html` — tela de login.
- `cadastro_artista.html` — página de cadastro de artistas.
- `cadastro_musica.html` — página de cadastro de músicas.
- `listagem_musicas.html` — página de listagem das músicas.
- `styles.css` — arquivo responsável pela estilização das páginas.

## 🚀 Como Executar o Projeto

1. Baixe ou extraia os arquivos do projeto.
2. Coloque todos os arquivos na mesma pasta.
3. Localize o arquivo `login.html`.
4. Abra o arquivo em um navegador de internet.
5. Utilize os links e menus disponíveis para navegar pelas páginas do sistema.

## 🖥️ Organização e Navegação

O sistema foi dividido em páginas diferentes para facilitar a utilização e manter cada funcionalidade organizada. A navegação permite acessar os formulários de cadastro, consultar a listagem de músicas e retornar à página principal.

## ⚠️ Observações

O projeto apresenta a estrutura visual e os formulários de um sistema musical desenvolvidos com HTML e CSS. As opções de login, cadastro, edição, exclusão e filtros estão representadas na interface, mas ainda dependem de implementação adicional para realizar operações completas e armazenar informações.

## 📚 Considerações Finais

O desenvolvimento deste projeto permitiu praticar a criação de páginas web, a organização de formulários, a utilização de tabelas e a aplicação de estilos com CSS.

Além disso, o projeto demonstra como diferentes páginas podem ser conectadas para formar a interface de um sistema, servindo como base para futuras melhorias e implementação de novas funcionalidades.
